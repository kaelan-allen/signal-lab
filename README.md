# Signal Lab

Signal Lab is a long-term digital signal processing (DSP) and software engineering project focused on RF signal analysis using software-defined radio (SDR).

The project serves three main goals:

1. Learn practical DSP
2. Build reusable C++ DSP software
3. Prototype and validate algorithms using MATLAB

---

## Features

Planned:

- FFT
- Power Spectral Density
- FIR filters
- FM demodulation
- IQ visualization
- GNU Radio integration
